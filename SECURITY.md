# Security and private material / 安全与私有资料

Experimental fixed-QEMU kernel; no production-security guarantee. No published private reporting contact has been confirmed. Establish an appropriate private channel with the owner before sharing sensitive reports; do not invent an email or open a public issue containing secrets. / 固定QEMU实验内核，不承诺生产安全；私密报告渠道待权利人确认。

The old comparison checkout and archives are outside the candidate. Never copy their credentials or history into this repository. Pattern scans report paths/rules/counts only and cannot prove absence of secrets. Publication of Git history, account metadata and raw evidence requires separate review. / 旧对照及归档排除；扫描不保证无秘密，历史/身份/原始证据另审。

Do not rotate credentials, change system permissions or install software as part of a report without applicable authorization. / 不擅自轮换凭据、改权限或安装软件。
